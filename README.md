# Project Hub demo

A fictional team-tool directory built with React/TypeScript and Python/FastAPI. Uses the approved workspace layout with Ocean blue & honey colors, English/Arabic with RTL, and light/dark modes.

Counselors browse/search/filter projects and open local fictional tool previews. Admins manage projects and accounts, including archived projects and private notes. Login offers two demo roles; it does not use Google or real credentials.

## Run locally

Requirements: Python 3.11+ and Node 22.12+; verified with Python 3.14 and Node 24. Google Chrome is used for browser tests.

Terminal 1, starting from this project folder:

```bash
cd backend
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-lock.txt
.venv/bin/python -m uvicorn backend.server.create_server:create_server --factory --app-dir .. --host 127.0.0.1 --port 8000
```

Terminal 2, starting from this project folder:

```bash
cd frontend
npm ci
npm run dev
```

Open **http://127.0.0.1:5173** and choose Admin or Counselor.

Projects, accounts, and sessions live in the Python process's memory. Browser refreshes keep edits. Stopping/restarting Python restores the original 12 projects and 6 accounts and requires login again. Fixture JSON is never changed by admin saves. Language/theme preferences are stored in the browser.

## Responsibilities

```text
frontend/src/
  data_models/        Plain data
  actions/            Named operations and pure display helpers
  server_connection/  API requests, response shapes, data conversion
  user_interface/     React pages, components, state, languages, appearance
  startup/            Connect parts and start React

backend/
  business_rules/     Entities, validation, access rules, visibility
  actions/            Named operations and storage interfaces
  connections/        Memory storage, fictional fixtures, response preparation
  server/             FastAPI URLs, cookies, startup, settings, logging
```

Each side owns its dependencies, settings, and tests. Communication uses documented API URLs/JSON. Core modules have no framework dependencies; startup injects concrete connections into actions. Only the HTTP adapter calls fetch. Server permissions are checked on every request; counselor responses omit archived projects/private notes.

Read [the API agreement](docs/api-contract.md), [standing engineering rules](docs/engineering-rules.md), and [folder responsibilities](docs/project-folder-structure.md).

## Checks

From `backend/`:

```bash
.venv/bin/python -m pytest
```

From `frontend/`:

```bash
npm test
npm run check:architecture
npm run build
npm run test:browser
```

Browser tests start the local servers if necessary. With existing servers they use the current demo run. They create/remove fictional test items; unit/API tests use isolated instances. The backend tests verify restart resets and unchanged fixture files. Both source checks enforce dependency direction, functions no longer than 30 lines, and at most four parameters.
